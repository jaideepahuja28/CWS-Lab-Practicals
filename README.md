# CWS-Lab-Practicals
## Authored by: Jaideep

### This repository hosts the documents of all the practicals of Cloud Web Services Lab, covered as per the syllabus.

* Course Title: Cloud Web Services Lab
* Course Code: BCA-381A
* Total Practicals: 15
* Practicals Covered: 7

# List Of Practicals:
1. Create an AWS Free Tier account and explore the AWS Global Infrastructure. 
2. Launch an Amazon EC2 instance (Linux/Windows), connect via SSH or RDP, install a web server 
(Apache/Nginx), and host a simple HTML webpage. 
3. Create an S3 bucket, upload/download files, set access permissions, enable versioning, and configure 
lifecycle rules for automated data management. 
4. To access the Billing Dashboard, view service costs, create a budget, set up billing alerts, and analyze 
usage patterns using AWS Cost Explorer for cost optimization. 
5. Install and configure AWS CLI, then perform S3 operations (create, list, upload, and delete 
buckets/objects) through command-line scripts. 
6. Creating RESTful APIs using AWS Lambda and API Gateway. 
7. Integrate Lambda functions with DynamoDB or Amazon RDS to perform CRUD (Create, Read, Update, 
Delete) operations using API Gateway triggers.
8. Secure REST APIs using AWS Cognito for user authentication or IAM roles for resource access; test 
using API keys and authentication tokens. 
9. Configure Identity and Access Management (IAM), create custom users and roles, attach permission 
policies, and enforce the principle of least privilege. 
10. Design a VPC with subnets, route tables, and Internet Gateway; launch an EC2 instance inside the VPC 
and verify connectivity via public and private subnets. 
11. Create and manage encryption keys in Cloud Key Management Service (KMS), apply them to protect 
data in S3 and EBS, and demonstrate decryption and secure key handling. 
12. Deploy multiple EC2 instances in Elastic Load Balancer and configure Auto Scaling groups to handle 
varying workloads automatically. 
13. Use Amazon CloudFront to deliver static content stored in S3, enable caching, and analyze latency 
improvements via edge locations. 
14. Create a CloudFormation template to deploy AWS infrastructure (EC2, S3, IAM), and configure 
CloudWatch dashboards and alarms for resource monitoring. 
15. Mini Project – Building and Deploying a Multi-Service AWS Application.
